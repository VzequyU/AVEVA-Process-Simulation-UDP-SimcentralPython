# Sample endpoint data

`dynamic_map_4tanks.csv` contains the nine endpoint rows supplied by the author from constant-input runs with q1 and q2 in {0.05, 0.08, 0.11} kg/s. Each row reports simulation time 20 seconds and four levels in metres.

The local Windows `packet_file` column was removed for publication. All remaining values were copied unchanged. Raw packet logs are not bundled. This table is an example of sampled fixed-horizon responses; it is not a complete dynamic reachable set, an operability index, or proof that input application and endpoint acceptance were independently verified.
